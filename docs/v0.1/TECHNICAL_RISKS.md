# 技术风险

| 风险 | 信号 | 缓解/停止条件 |
|---|---|---|
| 十类被当完备互斥本体 | 大量强制单标签 | 降为粗标签，以多轴 Schema 为准 |
| ID 被当语义数字 | 出现 ID 差值/排序推理 | 类型禁止算术，CI 检查 |
| 同一化污染 | `sameAs` 无法撤回 | IdentityDecision 版本化、可逆 |
| 未知/缺省/否定混同 | 缺字段解释成 false | 显式值对象、四值测试 |
| 因果过度声明 | “因为”生成 causal fact | 只生成 reported_cause |
| 时间冲突误报 | 不同有效期被判矛盾 | 双时间、区间与口径检查 |
| 模型污染知识 | 输出直接入正式表 | 候选区、验证、审核、审计 |
| 规则爆炸/循环 | 推导无界 | 有界规则、终止检查、资源限额 |
| 开放/闭世界混用 | 查无记录推出否定 | 每查询/规则声明假设 |
| 置信度伪精确 | 无校准的 0.93 | 保存方法/校准集，否则用序数等级 |
| 数据泄漏 | 模板变体跨集合 | 分组划分、近重复审计 |
| 指标投机 | 文本相似代替语义 | 预注册图/角色/逻辑盲测 |
| 基线不公平 | NCSC 获得额外信息 | 等数据/预算并披露人工工时 |
| 本体无限膨胀 | 每短语建概念 | 新概念门槛、反例、复用审查 |
| 过早基础设施化 | 服务多于样例 | 单体优先，按实测拆分 |
| 原生叙事领先证据 | 无基线即宣称优越 | 预注册实验，失败即降级 |

溯源不等于权限；模型能规划不等于能执行。UUID 不是访问令牌，RFC 9562 明确不应假定 UUID 难猜或可作安全能力。推导必须记录规则和输入版本，以便撤销错误派生知识。

最大未知：多轴 IR 是否超越普通事件 Schema/KG；概念漂移下的维护成本；开放域中文省略/多义的人审瓶颈；结构长度是否抵消验证收益；未来结构模型收益是否只是一般图结构收益。
