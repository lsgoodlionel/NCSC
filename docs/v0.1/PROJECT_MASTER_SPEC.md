## V1.0 语义目录

1. 语义优先、概念身份、显式关系、可计算逻辑、模型独立、允许原生化演进。
2. 0–9 十类是第一版研究假设；规范概念与 ID 一对一，语言表达可多对一或多义。
3. NCSC-DL 需表达角色、上下文、证据、否定、模态、数量、概率、来源和不确定性。
4. 原生语义、独立认知、通用交互三层；M01–M09 模块；学习不等于改词典。
5. 符号确定性计算与神经概率计算并行；身份、结构、向量、逻辑编码分离。
6. 汉语本体、概念生命周期、多义与不确定性。
7. 概念/事实/事件/规则/经验/目标记忆；认识状态；事实时间与获知时间。
8. 定义、分类、关系、因果、条件、概率、时间逻辑；冲突与因果边界。
9. 模型无关网关；模型只提候选，正式知识/规则/证据由 NCSC 管理。
10. 权限和元控制；提出行动不等于拥有执行权限。
11. Python 模块化单体；稳定存储；向量库仅辅助。
12. 阶段 0–5 路线和停止条件。
13. 语义、逻辑、跨模型、原生四组实验及公平基线。
14. 统一事实源、设计变更制度；核心公理和 ID 不随重构改变。
15. 分类、复杂度、ID/向量混淆、信息损失、规则冲突、模型依赖、范围膨胀风险。
16–20. 总任务书、首轮研究交付、三层验收、数学/时间/认知层级研究和最终决策。
