# 研究问题

## A：决定 V0.1 是否继续

1. 同数据、模型和预算下，NCSC 相对 JSON、属性图和逻辑基线能否显著降低否定/时间/来源/过度推论错误？
2. 十类作为粗标签是否有效？移除十类、只用多轴类型后是否等效或更好？
3. 合并、拆分、别名和漂移下，历史断言能否不重写仍可解释？成本多少？
4. 移除模型后，注册、验证、查询、有限推理、冲突候选和迁移是否全部可复现？
5. IR 对否定、量词、时体、模态、省略、指代、范围歧义可表达哪些，哪些必须保留原文及候选？

## B：认知边界

- 开放世界、显式否定、例外和冲突应采用何种形式语义？四值是否足够？
- 事实、用户陈述、模型推论、规则推论、验证因果如何可组合而不混淆？
- 双时间是否足够，是否需观察时间、发布时间和区间不确定性？
- 规则如何声明适用域、例外、优先级和终止性？
- 哪类冲突可确定判定，哪类只能人审？
- 概念边界由定义、判定程序、原型/反例还是社区约定维持？

## C：原生表示（长期、未验证）

- 图/超图、程序、张量关系或专用 Token 序列，何者在等算力下更适合结构预测？
- 不透明 ID 如何映射训练快照，既支持增量概念又不让编号顺序进入语义？
- 结构约束进入解码、损失、后验校正还是符号执行器？
- 能否直接从结构状态规划而不先生成自然语言？如何可证伪地测试？
- 新概念发现如何与正式注册分离，并量化提案纯度、覆盖和审核成本？
- 哪些收益来自 NCSC，哪些只是结构化数据、检索或工具调用的一般收益？

## 假设与证伪

| 假设 | 实验 | 降级条件 |
|---|---|---|
| 十类有价值 | 多轴+十类 vs 仅多轴 | 无提升或增加标注分歧 |
| NCSC 提升一致性 | 同义改写、替换解析器/模型 | 不优于 JSON/KG |
| 稳定 ID 降迁移成本 | 合并/拆分演练 | 历史需大规模重写 |
| 确定性层抑制幻觉 | 有/无验证规则 | 过度推论无显著下降 |
| 结构模型有原生优势 | 等数据/参数/算力 | 只因额外标注/计算获益 |

W3C 规范只证明互操作组件存在；Pearl 的 SCM 只提供依赖假设的因果形式；语义解析论文只说明评测敏感性。它们都不证明 NCSC 的原创公理、通用认知或原生模型优势。

启动前还需产品回答：首域及用户；标注/本体预算；唯一主价值指标；零容忍错误；失败后保留与停止的部分。
