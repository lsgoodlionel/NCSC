# M2 循环溯源的本地实现决策

适用于 `query-preview`。同一查询分区内，先对带极性的事实求闭包，记录满足条件的具体规则边。闭包停止条件为本轮没有新增事实。规则边保存有序前提，多个规则实例可以指向同一事实。

从查询结论向原始断言展开解释时，每条根到叶路径上的事实只能出现一次。沿回边遇到重复事实时丢弃该证明分支，继续枚举其他路径。兄弟前提各自维护祖先集合，因此两个前提可以引用同一个来源。直接断言按自身 ID 保留；同一规则的不同前提证明组合分别产生证据。

每条保留的派生证明按 P-2 对规则名和有序前提 ID 的紧凑 JSON 计算 SHA-256，取前 32 位十六进制。P-5 的 trace 与前提同序，来源按首次出现的 ID 去重。完整诊断图可以含回边；对外解释只含有原始断言作为叶子的证明树。

例如有 A 的直接证据和 A→B→A：查询 B 时保留从 A 到 B 的证明；回到 B 的路径不再展开。若 A 有两条独立的原始断言，B 仍有两份证明。

在有限事实集上路径深度有界，但无环证明的组合数仍可能很大。目前尚未测量大图资源消耗。生产入口需要明确枚举预算及超限错误，避免截断后仍宣称解释完整。
