# 实验设计：十类标签是否有价值

关联 #6 验收项“为十类假设给出可证伪对照”，以及 `docs/v0.1/RESEARCH_QUESTIONS.md` 中的 A2 与“假设与证伪”表。

状态：**预注册草案**。本文只是设计，尚未运行，不含任何结果。判定门槛必须在第一次测量之前经负责人确认并冻结。

## 1. 假设

V1.0 原文提出十类：0 空、1 物、2 系、3 动、4 性、5 域、6 时、7 量、8 理、9 界。项目约束要求把它当作**待检验假设**，而不是公理。本实验检验以下两个可证伪的命题：

- **H1（可标注性）**：人类标注者能够稳定地给概念打上十类标签。
- **H2（有用性）**：在多轴类型（P-1 的 `kind` 等）之外加上十类标签，能够改善下游任务；如果去掉十类，下游表现会变差。

## 2. 对照设计

| 组 | 标注层 | 用途 |
|---|---|---|
| M（对照） | 只有多轴类型（`kind`） | 基线 |
| M+T | 多轴类型 + 十类标签 | 实验组 |
| T | 只有十类标签 | 检验十类能否替代多轴类型 |

- 三组使用同一批概念、同一批标注者，组的顺序做平衡（一半人先标 M，一半人先标 T），以抵消学习效应。
- 十类标签存放在独立的实验标注层 `annotation/ten-class/<数据集>.tags.json`，**不进入 IR**，内核不读取。
- 标注单位是概念（登记表中的条目），每个概念允许多个十类标签，并记录标注者认为“无法归类”的情况。

## 3. 测量

### H1：可标注性

| 指标 | 定义 |
|---|---|
| 单标签可归类率 | 标注者只给出一个十类标签的概念所占比例 |
| 无法归类率 | 标注者认为十类都不合适的概念所占比例 |
| 十类一致性 | 两名标注者标签集合的 Jaccard 均值；另报单标签子集上的 Cohen's κ |
| 多轴一致性 | 同一批概念在 M 组中 `kind` 的 Cohen's κ（作为参照） |

### H2：有用性

可在两个下游任务上测量，前提是对应里程碑已有可用实现：

1. **规则适用性**：在 P-4 的规则格式中，用十类作为前提的类别约束，与用 `kind` 作约束相比，过度推论数和漏推论数（需要 #5）。
2. **解析一致性**：模型适配层（#8）输出候选 IR 时，在提示中提供十类信息与不提供，概念规范化准确率与同义改写一致率的差异（需要 #8 与 M3 冻结数据）。

## 4. 预注册判定规则（门槛待冻结）

以下门槛只是**提议值**，由负责人在第一次测量之前确认或修改；冻结之后不得根据结果调整。

| 结论 | 条件 |
|---|---|
| 十类降为仅供参考的粗标签（不再投入） | 满足任一条：单标签可归类率 < 70%；无法归类率 > 10%；十类一致性的 κ 低于同批 `kind` 的 κ |
| 十类保留为可选的实验标注层 | H1 未触发降级，但 H2 的两个任务都没有显示改善（差异在重复运行的波动范围内） |
| 十类值得进一步研究 | H1 未触发降级，且 H2 至少一个任务在预先指定的划分上稳定改善，并且在等量标注成本下仍然成立 |

## 5. 已知反例（用于标注材料）

`docs/v0.1/ENGINEERING_FEASIBILITY.md` 中的反例（会议、红色、北京、三次、禁止进入、若下雨则取消、未知与缺省）必须包含在标注材料中。它们是十类最可能失败的地方；如果在这些反例上标注一致性显著低于整体，需要单独报告。

## 6. 成本与公平性

- 记录每组的标注耗时。若 M+T 的收益只来自额外的标注工作量，应与“同样工时用于补充多轴标注”进行比较。
- 结果无论正负都要报告；不得只报告支持十类的部分。
