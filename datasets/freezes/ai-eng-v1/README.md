# AI 工程验收集 ai-eng-v1

2026-11-23 项目负责人批准以 AI 独立试标、第三方 AI 裁决和工程复核作为本轮 #6 的准出依据。该决定适用于本版本。真人准备轮仍为 pending，r1 原始记录保持原版本。

## 范围和使用方法

- **#7 给定 IR 查询**。从 `synthetic-v0/items.json` 读取 26 个条目的断言及 42 问，按已声明的 IR、来源、上下文和日期评分。该输入及期望查询结果在冻结前已公开、反复用于调试。冻结用于锁定同版本工程回归。
- **#8 从原文抽取**。使用 r1 盲包中的原文、登记表与任务规范，只将受控的独立裁决表交给评分者。按条目、主体、关系、客体、极性、上下文和日期组成的集合，跨条目累计 TP、FP、FN；精确率 TP/(TP+FP)、召回率 TP/(TP+FN)，分母为零记 null。另报无法产出、校验拒绝和可核验来源。评估器应计入整个预定条目集，漏答的目标计为漏抽。同条、同键的多来源可合并为来源集合；来源的具体证据仍应逐项核验。
- **划分**。八个场景族全部固定在同一工程开发分区，未随机拆分，种子不适用。没有独立训练分区或隐藏测试分区。模型或提示词的样本外效力仍需新语料和真正隔离的评测。
- 对照裁决表与原有查询夹具时，13 条至少有一处断言、来源分组或未标片段差异。部分查询夹具提供了原文未明确的上下文或来源；另有单条多来源与多条同义断言的表示差异。抽取时不得由查询夹具补足这些字段。对当前版本的两个用途分别绑定参考，避免按模型成绩修改目标。

## 验收证据

两个非继承历史的 Codex 会话分别锁存 26 条原始输出，第三个 Codex 会话完成 4 条边界分歧裁决，未决 0。裁决前断言集 F1 为 1（双方各 24 个键），未标片段 F1 为 38/48。20 个共同极性键含 4 个正反并存键；其余 16 个单极键全部一致。遵从原协议记录 κ=null。裁决者逐条复核，报告因果误升级计数 A 和 B 各为 0。两方共用模型家族、合成材料和指南，不推断真人可靠性。

逐条核对 A/B、裁决结果、公开参考和固定报告后，对四处分歧采纳以下指南补充：圈缺记录对象时可去外层引语；需求来源缺失时只圈定位该缺口所需的分句；不同来源分别表态时每个来源各占一项；不同日状态分开圈，承前主语不补写入原文。当限定会改变所指时保留。补充规则供后续版本使用；r1 的原始评分口径保持锁存。r2 仅作准备。十类假设的验收项是现有可证伪设计，r1 未开展十类实证或冻结其结论。

## 复核

`FROZEN.json` 记录公开文件和受控材料的 SHA-256、版本以及稳定分区映射。从仓库根目录运行：

```sh
python3 -m annotation.verify_ai_freeze
python3 -m unittest tests.datasets.test_synthetic_v0 tests.test_trial_metrics tests.test_ten_classes -v
```

持有受控 r1 快照的协调人可给第一个命令追加 `--pilot <快照目录>`，校验私有文件、语料绑定、裁决覆盖和裁决前统计。受控答卷、裁决详情与参考抽取表保存在本机独立仓库。
